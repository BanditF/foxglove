# Right-hand screen art

`widgets/custom_art.c` is generated by `scripts/flipper_art.py`. Regenerate it whenever the art changes:

```
python scripts/flipper_art.py boards/shields/nice_view_custom/widgets/custom_art.c <inputs...> --preview preview.png
```

Inputs can be Flipper animation folders (meta.txt + frame_N.png/.bm), single images, single
`name_128x64.bm` files, or LVGL C files of 1-bit nice!view images. Only use art whose license
allows redistribution: this repo is public.

Orientation: the nice!view is mounted portrait, so the art area is 68 wide x 140 tall, below the
status strip. Inputs are fitted upright into that by default, which suits nice!view art
(68x140). Wide Flipper art (128x64) would shrink to 68x34 that way, so it gets the `:landscape`
option: it is stored as-is and reads sideways on the keyboard. The `--preview` sheet shows each
set as it looks on the keyboard.

Size limit: the nice!nano bootloader (v0.6.0) only accepts firmware up to 0xAD000, which leaves
roughly 270 KiB for art on the right half. Frames are stored as RLE-packed XOR deltas (about a
third of their raw size) and unpacked on the keyboard; the script prints the compressed size, so
keep that under ~240 KiB.

Current art: only portrait (upright) sets. The 30 signed Hammerbeam slideshow pieces were removed on 2026-10-21: their signature is the artist's attribution, so they are used as-is or not at all; wide Flipper art reads sideways and was left out. Inputs used for the current `custom_art.c`, in order (paths are local checkouts of the sources above):

```
zmk/app/boards/shields/nice_view/widgets/art.c:stills:name=ZMK:labels=ZMK balloon|ZMK mountain
urchin-peripheral-animation/assets/example/animated/art.c:fps=1:name=Corro_urchin:label=Corro the urchin
nice-view-gem/boards/shields/nice_view_gem/assets/crystal.c:fps=8:name=Gem_crystal:label=Gem crystal
art-src/bandit/out/Bandit_<Scene>:name=Bandit_<Scene>:label=Bandit <scene>   (for boot idle lock emblem radar signal decrypt uplink vitals route dossier standby skyline, in that order)
```

The run also writes `widgets/custom_art.json`, which Foxglove uses to name the built-in sets.
