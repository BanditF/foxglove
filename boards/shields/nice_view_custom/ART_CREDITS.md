# Right-hand screen art

`widgets/custom_art.c` is generated by `scripts/flipper_art.py`. Regenerate it whenever the art changes:

```
python scripts/flipper_art.py boards/shields/nice_view_custom/widgets/custom_art.c <inputs...> --preview preview.png
```

Current art:

- Dolphin animations (first frames) from the official Flipper Zero firmware,
  https://github.com/flipperdevices/flipperzero-firmware/tree/dev/assets/dolphin/external
  (GPL-3.0): Boxing, Doom, Furippa1, Kaiju, Painting, Read_books, Sleep, Coding_in_the_shell,
  Dj, Hacking_pc, Soldering, Freedom_2_dolphins.
