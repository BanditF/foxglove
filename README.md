# Foxglove

Firmware and desktop tooling for an Eyelash Peripherals Corne (ZMK v0.3, nice!nano + nice!view).

- **Firmware**: the keymap, the `nice_view_custom` shield (framed left screen, animated art on
  the right) and the PC link, all at the repo root, where ZMK's build expects them.
- **Digitalis**: the link between the PC and the keyboard over Raw HID. The PC draws a 64x52
  panel on the left screen (`0xD5`), and pushes art to the right screen through the left half and
  the BLE split link (`0xD6`). The protocol is in
  [`host_link.h`](boards/shields/nice_view_custom/widgets/host_link.h) and
  [`art_relay.h`](boards/shields/nice_view_custom/widgets/art_relay.h).
- **App** (planned): one tray app combining the KeyPeek layer overlay with the screen panel, in
  `crates/` and `app/`. See [docs/proposal.md](docs/proposal.md).

The name: Digitalis, "of the finger", is the Latin name the botanist Leonhart Fuchs gave the
foxglove in 1542.

**This board is not foostan's Corne.** Standard `corne` firmware does not work on it.

## Layout

| Path | What |
|---|---|
| `config/` | keymap, `west.yml`: ZMK v0.3.0, the board from Eyelash Peripherals, [zmk-raw-hid](https://github.com/BanditF/zmk-raw-hid) (`nonblocking`), [zmk-keypeek-layer-notifier](https://github.com/srwi/zmk-keypeek-layer-notifier) |
| `boards/arm/eyelash_corne/` | board definition (from Eyelash Peripherals) |
| `boards/shields/nice_view_custom/` | custom screens, host link, art relay ([art credits](boards/shields/nice_view_custom/ART_CREDITS.md)) |
| `scripts/flipper_art.py` | builds the right-hand art (`custom_art.c`, or a `.bin` blob to push) |
| `keymap-drawer/` | keymap diagram, redrawn by CI |
| `crates/`, `app/` | desktop side (coming; `app/keypeek` will be a submodule) |
| `docs/` | design notes; [`docs/upstream/`](docs/upstream/README_EN.md) has the vendor's original README |

## Building and flashing

Every push that touches the firmware runs **Build ZMK firmware** (GitHub Actions; the matrix is
in `build.yaml`). Changes only under `crates/`, `app/`, `docs/`, `keymap-drawer/` or to Markdown
files don't start a build. Download the artifact, then:

1. Put **one** half in the bootloader (double-tap reset). Check which half it is before you copy
   anything: copying the wrong UF2 leaves that half with the other half's firmware.
2. Copy the UF2 for that half onto the drive that appears: `eyelash_corne_studio_left` for the
   left, `nice_view_custom-eyelash_corne_right` for the right.
3. Keymap-only changes need only the left half (the central).

The nice!nano bootloader (0.6.0) refuses images that end past `0xAD000`. An oversized UF2 leaves
the half in the bootloader; double-tap reset to recover.
