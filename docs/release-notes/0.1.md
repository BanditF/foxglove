# Foxglove 0.1

*Draft. The release agent finalises it when 0.1 is tagged.*

Foxglove is the software for the Eyelash Corne split keyboard with two nice!view screens:
firmware for the keyboard and a Windows tray app. The keyboard does everything on its own
(typing, layers, both screens, lights). The app adds a layer overlay, a PC-drawn panel on the
left screen, an art library for the right screen, profiles and plugins. Quit the app and the
keyboard keeps working.

This is the first release. Start with the [user guide](../user-guide.md).

## Highlights

- **Layer overlay.** When you change layer, a picture of that layer's keys pops up on screen. Pick
  the monitor, size, colours, which layers show it, and how long it stays. The overlay comes
  from [KeyPeek](https://github.com/srwi/keypeek) by Stephan Rumswinkel.
- **Left screen.** Battery, connection, layer and held modifiers, as before, plus:
  - **Bluetooth profile boxes, 1-5.** The active profile is filled, connected ones are
    outlined, and a word says LINKED, SEARCH, PAIR or USB. The block flashes inverted after a
    profile change and while SYSTEM is held, so a wrong-profile mix-up is easy to spot.
  - **A panel drawn by the PC:** the clock, what's playing, the volume, and game hints for
    programs you choose. It can also show the current Wallpaper Engine wallpaper's animation.
- **Right screen art.**
  - **Built-in animations,** including the Bandit set.
  - **Your own:** push an animation from a file, or **save** one on the keyboard so it stays
    after a power cycle.
  - **Hotlist:** cycle through favourites every few minutes, or each time the lights wake.
  - **Match the wallpaper:** with Wallpaper Engine, the keyboard shows the art that goes with
    the wallpaper on screen.
- **Profiles.** Save variations of your screens, lights and art settings, for example a "Game"
  profile.
  - Switch from the tray or Settings, or automatically when a given program comes to the front.
  - Share them as files.
- **Accent lighting.** The underglow can follow the Windows accent colour. Lights, effects and
  keyboard actions are all in **Settings → Keyboard**.
- **Plugins tab (preview).**
  - What it shows: installed plugins, a catalog, and installing from a file after you approve
    exactly what the plugin may do.
  - Catalog entries are listed as "Coming soon" in 0.1.
- **A flashing script.** `scripts/flash/foxglove_flash.py` updates both halves safely:
  - it checks that each file belongs to that half before writing;
  - it does the left half first and checks it types;
  - it reads back the version each half runs.
  - When it asks, put the half into its bootloader: **SYSTEM + C** (left) or **SYSTEM + comma**
    (right), or double-tap its reset button. The release firmware has no way for the PC to do
    this for you.
- **Other keyboards.** Read-only support for VIA/QMK keyboards (keymap, layers and lights).

## Battery life

The right half used to be down to 20% after a day. 0.1 cuts its idle drain:

- **Backlight:** switches off while a half is idle, and comes back on at the next key press.
- **Right-half radio:** transmits at lower power. It only talks to the left half, a few
  centimetres away.
- **Underglow:** dims to about 30% on battery, and runs at full brightness on the cable.
- **Deep sleep:** both halves sleep after 30 minutes idle (was 60). A key press wakes them.

## New layer layout: SYSTEM

The Bluetooth, output and reset keys moved off NUMBER and SYMBOL to a new **SYSTEM** layer, so
they can't be pressed by accident.

- **To reach SYSTEM,** hold both middle thumbs (FUNCTION), then also hold **Tab**.
- **Its keys:**

  | key | does |
  |---|---|
  | Q W E R T | Bluetooth profiles 1-5 |
  | Y / U | USB / Bluetooth output |
  | A | back to QWERTY |
  | Left Ctrl | clear the current profile |
  | Esc | clear **all** pairings |
  | M (hold 2 s) | turn both halves off |

- **FUNCTION** keeps F1-F12, mouse and media, and adds Caps Lock on A and Insert on Z.

The old positions on NUMBER/SYMBOL now do nothing. Full map: [layers.md](../layers.md).

## Known limitations

- **The installer isn't code-signed.** Windows SmartScreen warns "Windows protected your PC":
  click **More info**, then **Run anyway**. Signing comes in a later release.
- **Automatic updates are off in 0.1.** **Settings → Updates** links to the releases page;
  install new versions from there.
- **Windows Dynamic Lighting** isn't supported yet, including control from Windows while
  Foxglove is in the background. It needs a signed app identity and comes later.
- **Plugins are a preview.** Only signed plugins install and run. The first-party plugins
  (focus timer, OpenRGB, and others) are published once plugin signing is in place, planned
  for the next milestone (M6). Until then the catalog shows them as "Coming soon".

## Upgrading

1. **Quit Foxglove** if a development build is running (tray → **Quit**).
2. **Install the app:** run `foxglove-x64.msi` from the release. Your settings in
   `%APPDATA%\Foxglove\config` are kept.
3. **Update the keyboard's firmware on both halves,** from the same 0.1 build: the left half
   first, check it types, then the right. With the flasher:

   ```powershell
   python scripts/flash/foxglove_flash.py --firmware <folder with the 0.1 UF2s> --half both
   ```

   When the flasher asks, put that half into its bootloader: **SYSTEM + C** on the left,
   **SYSTEM + comma** on the right, or double-tap its reset button. Bluetooth pairings survive
   a normal flash; only a settings reset clears them.
4. **Learn the new SYSTEM layer** (above): Bluetooth profiles are no longer on NUMBER/SYMBOL.
5. **Check:** **Settings → Keyboard** shows both halves on the same firmware version. If the halves
   differ, it shows a warning; flash both from the same build.

## Firmware (Eyelash Corne, nice!nano + nice!view)

Version 0.1.0 (`boards/shields/nice_view_custom/FIRMWARE_VERSION`). Four images, named
`foxglove-fw-v0.1.0-<sha>-{left,right}-{dev,ga}.uf2`, plus `settings-reset`.

- **GA** is for everyone: no test hooks. The split guard is on.
- **Dev** adds the test hooks the Test lab uses: position press (D7 05), bootloader (D7 08) and guard test (D7 0B).
  Only dev builds can be put into the bootloader from the PC; from GA, use SYSTEM + C, SYSTEM + comma
  or the reset button.

What's in it:
- **Host link** over Raw HID: the right screen's panel, art push to the right half with 8 saved slots, RGB sync, connection state, build info and screen read-back.
- **Split guard:** a split link that isn't encrypted within 20 s is dropped and retried, at most 3 times. The drop count shows in HELLO byte 31.
- **Battery** (#218):
  - The underglow dims to 30% on battery and returns to full brightness on USB, on each half.
  - The backlight turns off while idle.
  - The right half transmits at 0 dBm.
  - Deep sleep after 30 min.
- **Without the PC app** (or when the cable drops), the keyboard keeps typing normally and the screens keep what they were showing.

Flashing: the left first, then the right. Check which half is in the bootloader by its USB serial
(left 1E89EF085AA8A635, right 35B4541F78DE9CF8). See RESCUE.md for rolling back.
