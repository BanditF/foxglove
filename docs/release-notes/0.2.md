# Foxglove 0.2

*Draft, from the pull requests merged to main since `release/0.1` branched (#216 onward). The
release agent finalises it when 0.2 is tagged. Some fixes here also went to 0.1.x.*

0.2 turns the Plugins tab into a working plugin system, with its first plugins, and makes the
app and firmware quieter: nothing runs on a timer that an event could start instead.

## Highlights

- **Plugins you can use.** Installed plugins run in a sandbox, with only the permissions you
  approve, and can now:
  - hold the lights for a while and give them back cleanly (**lighting leases**), so a
    notification wins over a colour sync and the lights come back as they were;
  - draw on the left panel, react to keys you bind (F13–F24), keep passwords in Windows'
    credential store, and have settings in the Plugins tab;
  - reach the network only where their permissions say, through Foxglove.
- **First plugins:**
  - **Pomodoro:** a focus timer on the left panel and the underglow, with keys to pause and
    restart. It survives restarts and sleep.
  - **Mic mute:** red and MUTED while your microphone is muted, and a key to toggle it.
  - **Broadcast Status:** OBS recording or streaming as REC or LIVE, with the scene name.
  - **OpenRGB (E1.31):** now holds the lights with a low-priority lease, so notifications still
    show.
  - **Corsair iCUE:** the underglow mirrors a Corsair device's colours (bring Corsair's SDK).
  - **Foxglove for SignalRGB:** SignalRGB drives the underglow through Foxglove's E1.31
    receiver, under the same low-priority lease.
- **Lighting presets.** Curated underglow looks that match the Bandit wallpapers, with matching
  right-screen art if you want it.
- **Art.**
  - **Art library view:** browse built-in, saved and your own animations.
  - **Art follows the layer or preset**, and `&art_next` / `&art_prev` step the right screen's
    art from a key.
- **More keyboards.**
  - **Board profiles:** a new board is a profile file plus firmware, without app changes. The
    Eyelash Corne is built in. The Toucan2 and Halcyon Corne e-paper profiles are there but
    untested.
  - **Toucan2:** a PC-drawn panel on its 144×168 screen.
  - **VIA keyboards** (such as the Keychron K5 Pro), read-only, with a per-keyboard **Pause
    Foxglove** so VIA or the maker's app can use it.
- **Battery.** The backlight turns off while idle, the underglow dims to 30% on battery, the
  right half transmits at lower power, and the keyboard sleeps after 30 minutes idle.

## Features

- **Plugin API 1.3** (`docs/local-api.md`):
  - **Lighting:**
    - leases with low, normal and high priority (#250);
    - restore checked on readback, including speed, with the snapshot kept until it takes
      (#317);
    - leases changed in place, and the E1.31 receiver holds a lease (#330);
    - waits for a split keyboard's other half to catch up (#261).
  - **Left panel:** overrides held until replaced or released (#310, #255).
  - **Key actions** bound to F13–F24 (#241).
  - **Per-plugin secrets** in Windows' credential store (#249).
  - **Plugin settings,** including a random pairing token (#324).
  - **Network through Foxglove:**
    - scoped `net.connect` and `net.listen` (#232);
    - loopback TCP listening, plus the SDK's WebSocket server side (#323).
  - **Facts:**
    - the microphone as `mic.*`, with mute through Foxglove (#251);
    - media as facts (#235);
    - `keyboard.layer`, `keyboard.right.battery`, `keyboard.link` and more (#321).
  - **Waiting for an app:** `apps.watch` tells a plugin when an app's window opens or closes
    (#296).
- **Plugin catalog v2,** with publishing through GitHub Releases and Pages (#217, #219).
- **New look** (#384, first step of the UI overhaul #393): dark graphite with Bandit orange,
  Chakra Petch headings, IBM Plex Sans and Mono text (bundled, SIL OFL). Theme picks Dark,
  Light or System for the windows; the layer overlay keeps its look.
- **Settings in pages** (#385): a sidebar with Keyboard, Lights, Screens, Plugins and Settings,
  the profile picker at its foot, and a status strip for both halves (connection, firmware,
  link, battery, Bluetooth profile, and a warning when unplugging would leave the keyboard
  unable to type). The window remembers the last page.
- **Keyboard page** (#386): the board at the top (click a screen or the lights to open that
  page), a Firmware card with "Ask the keyboard again", an Actions card grouped by kind, and
  the link to this PC in plain words ("Left half: on USB", "Right: no reply yet").
- **Lights page** (#387): effect pills, colour swatches with a custom hue and saturation,
  brightness and speed sliders (speed is new in the app), the accent and right-half switches,
  Apply colour, and both halves' state with Refresh. The presets card waits for #306.
- **Screens page** (#388): the left screen's card (live preview, Drive, Pause, Show, game
  hints) beside the right screen's art: what's playing, the library as small 1-bit thumbnails
  (each piece once, no unreadable rows), Push file..., "Saved on the keyboard: 1 of 8" with
  the slots behind a click, and the hotlist as pills with Next.
- **Plugins page** (#389): one card per plugin, three to a row, with its tag (CATALOG,
  INSTALLED or SIDELOADED), On, Settings and Remove; plugins that run outside the sandbox say
  so on the card. "Install from file…" sits in the page header, and the catalog's state reads
  "Catalog: up to date" with Check now. Catalog plugins show Install greyed out until their
  downloads exist.
- **Plugins tab:** icons, an empty state, the app icon and tray glyphs (#206, #299).
- **Lighting presets** and matching right-screen art (#265, #273).
- **Art:**
  - cycling triggers (layer, preset, key) (#300, #302);
  - the library view and source folders (#303, #308).
- **Right underglow:** gets the PC's colour over the relay, acknowledged, newest wins (#269).
- **Board profiles** (#339), **Toucan2 panel** (#216), and **wide or tall panels** with
  `ROWS_AT`, reserved screen formats shown as unsupported (#294, #337).
- **VIA keyboards,** stage 1 (#325):
  - no switch-matrix reads, Vial refused;
  - "Active layer: unknown";
  - pause per keyboard.
  - Keyboards without a reliable USB serial are told apart by where they're plugged in, with a
    **This is the same keyboard** confirmation (#326, #328).
- **Firmware power:** idle backlight off, 0 dBm right half, 30% battery dim, deep sleep after
  30 min, a slower display tick (#220–#223, #290).

## Fixes

- **Lights:**
  - retried when the keyboard is busy (#224);
  - plugins can change them before the overlay opens the keymap (#203);
  - restored with speed and brightness, and retried on the next connect if a restore didn't
    take (#317).
- **OpenRGB:** each colour confirmed on the keyboard, sequence numbers per sender (#244, #247).
- **Plugin runner:** notices a plugin's exit even when its output stays open (#240). A stopped
  plugin no longer leaves its thread and registration behind (#296).
- **Plugin access:** outside tools are never granted plugin secrets (#271), and the OpenRGB
  catalog entry asks for its port, not unrestricted network (#322).
- **Flasher:** never prompts a double tap while a hands-free entry may still land (#205).
- **MSI:**
  - a rebuilt same-version MSI replaces the installed one;
  - tag builds set the MSI version correctly (they passed `--version`, which built nothing);
  - the plugin host builds on Linux (#309, #319).

## No more polling

Nothing in the app, the plugins or the firmware runs on a free timer any more. Each poll that
remains is started by an event, stopped by one, and bounded (#278, #283):

- **Plugin host and SDK:**
  - no heartbeat or silence watchdog; exits come from the process handle (#310);
  - panels are held, not re-sent;
  - OpenRGB blocks on frames, and Pomodoro doesn't tick while paused (#310).
- **App** (#311):
  - **Panel keep-alive:** none when the firmware holds the panel (`PANEL_HOLD`, #285).
  - **Preview:** it repaints on a new frame.
  - **Reconnect:** it waits for the device to arrive, after a bounded burst.
  - **Crashing services:** they stop after 5 failures.
- **Idle wake-ups:** repaints come from the workers, and the ZMK and UDP readers block (#316).
- **OBS:** connects when OBS's window appears, not on a timer (#296).
